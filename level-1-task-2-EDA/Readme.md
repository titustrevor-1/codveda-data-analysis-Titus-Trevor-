# Task 2: Exploratory Data Analysis (EDA) using the iris dataset.

## Objective
Find summary statistics, make charts, and check the correlation between the number columns.

## Dataset
- Iris flowers (iris.csv)
- 150 rows, 5 columns (4 measurements and the species)

## What I Did
1. Loaded the data and checked its size, types and missing values
2. Calculated the mean, median, mode and standard deviation
3. Made histograms, boxplots and scatter plots
4. Found the correlation between the number columns and drew a heatmap

## Main Findings
- Setosa has the smallest petals and is clearly separate from the other species
- Petal length and petal width have a very strong correlation
- Sepal width has the weakest link with the other columns

## Tools
Python, pandas, seaborn, matplotlib
